# Support Intelligence

Локальный ассистент службы поддержки с русским веб-интерфейсом и FastAPI. Он ищет ответ в статьях базы знаний, показывает выдержки с источниками и помогает разобрать обращение. Отдельная модель классифицирует англоязычные банковские обращения по 77 категориям.

## Быстрый запуск

В терминале из корня репозитория выполните:

```powershell
python -m pip install -r requirements.txt
python scripts/start_demo.py
```

Откройте [интерфейс](http://127.0.0.1:8000/) или [Swagger](http://127.0.0.1:8000/docs). Скрипт подготавливает поисковую конфигурацию для [корпуса проекта](data/demo/articles.jsonl) и запускает API. В базе 17 коротких статей о самом проекте. Во вкладке **«Ответ по базе»** выберите русский язык и точные выдержки из источников. На вопрос «Что такое АПИ?» должна появиться выдержка из статьи `api_definition_ru`. Этот режим работает без языковой модели. Во вкладке **«Чанки»** можно вставить свой текст и посмотреть границы фрагментов.

Для вкладки **«Агент»** нужна запущенная локальная Ollama с моделью планировщика. Если Ollama установлена на компьютере и доступна по стандартному адресу, остановите демосервер и запустите его из PowerShell с такими настройками:

```powershell
ollama pull qwen2.5:1.5b
ollama pull qwen2.5:0.5b
$env:AGENT_MODEL = 'qwen2.5:1.5b'
$env:OLLAMA_MODEL = 'qwen2.5:0.5b'
python scripts/start_demo.py
```

Первая модель выбирает действия агента. Вторая доступна для режима подготовки ответа через Ollama.

## Как работает агент

Во вкладке «Агент» задайте вопрос «Как установить зависимости проекта?». В зафиксированном запуске Qwen выбрала поиск, получила результат выше порога и запросила подготовку ответа. Сервер сверил источник, идентификаторы статьи и чанка и точное вхождение цитаты в текст. Пользователь получил выдержку из инструкции по установке. В интерфейсе видны шаги и источник. [Код агента](src/agent/service.py) · [Запись запуска](reports/workspace_validation.json)

Для запроса «Ничего не работает» сервер сразу просит уточнить симптомы. Для английского обращения планировщику также доступен классификатор BANKING77. Если источников недостаточно, агент может уточнить вопрос или подготовить черновик обращения оператору. Отправка черновика остаётся за человеком. По умолчанию на обращение отводится до четырёх шагов.

## Поиск и ответы через API

- `POST /v1/knowledge/search` возвращает найденные фрагменты, источники, оценки релевантности и состояние порога. Статьи разбиваются по предложениям с лимитом 900 символов и перекрытием до одного предложения. [Реализация](src/rag/chunking.py)
- `POST /v1/knowledge/answer` готовит ответ с цитатой. HTTP 200 со статусом `abstained` означает, что запрос обработан, но данных для ответа недостаточно. Например, в демонстрационной базе нет актуальных ипотечных ставок. Увеличение `top_k` расширяет список кандидатов и сохраняет проверку порога.
- `POST /v1/agent/run` возвращает ответ, уточнение или черновик, а также последовательность действий агента.
- `POST /v1/classify` принимает, например, `{"text":"I lost my card"}` и возвращает категорию. Для работы нужен обученный артефакт модели. Его готовность проверяет `GET /health/ready`, а готовность индекса — `GET /health/knowledge/ready`.

## Обучение и разбор в PyCharm

Для самостоятельного обучения подготовьте данные по [инструкции](reports/README.md), откройте [ноутбук обучения](notebooks/01_model_training_and_metrics.ipynb), выберите интерпретатор с установленными зависимостями и выполните ячейки сверху вниз. Там доступны распределения классов, сравнение моделей, ошибки и сохранённые метрики официального теста. Запуски сохраняются в локальном MLflow.

Для изучения поиска откройте [сравнение ранжировщиков](notebooks/07_hybrid_search.ipynb), для разбора решений модели — [ноутбук агента](notebooks/08_operator_agent.ipynb). Формат собственной базы и разметки описан в [контракте данных](data/knowledge/README.md). Пошаговое объяснение разработки, экспериментов и ограничений собрано в [руководстве Word](docs/development_guide.docx).
