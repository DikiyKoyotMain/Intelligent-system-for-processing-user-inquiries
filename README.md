# Support Intelligence Lab

Учебный проект по построению системы обработки обращений службы поддержки: от анализа открытых данных и простых моделей классификации намерений до поиска по базе знаний, RAG и API.

## Текущий этап

**Этап 1 — исследование.** Сравниваем открытые датасеты, фиксируем постановку первой ML-задачи и план экспериментов. Обучение моделей и загрузка датасета начнутся после рассмотрения результатов исследования.

## Репозиторий

- `reports/research.md` — выводы этапа исследования, сравнение данных, архитектура и план.
- `docs/study_guide.docx` — учебный документ, который обновляется вместе с этапами.
- `data/raw/` — исходные файлы данных (не коммитить большие/персональные данные).
- `src/` — код пайплайна и приложения.
- `experiments/` — конфигурации и результаты воспроизводимых экспериментов.

## Git-процесс

Изменения фиксируются небольшими логическими коммитами по завершении этапа или проверяемого подэтапа. Рекомендуемый формат: `stage-N: краткое описание`. Перед публикацией нужно настроить `origin`; адрес удалённого репозитория пока не задан.

## Статус

Результаты моделей, EDA и метрики пока отсутствуют и не приводятся как факты. Для первого эксперимента рассматриваем BANKING77; точные характеристики локальной копии будут перепроверены при загрузке.
